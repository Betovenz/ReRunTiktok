# LiveBMKode AdminWEB

หน้าจัดการลูกค้า แพ็กเกจ และประกาศ แยกออกมาจากโปรเจกต์ `rerun_tiktok_bmkode` เพื่อให้เปิดใช้ง่าย ไม่ต้องยุ่งกับโค้ดแอปหลัก

ต่อ MongoDB Atlas ตัวเดียวกับแอปหลัก ข้อมูลจึงเป็นชุดเดียวกันเสมอ แก้ที่นี่แอปหลักเห็นทันที

## วิธีเปิด

ดับเบิลคลิก **`START-ADMIN.bat`**

ครั้งแรกจะใช้เวลา 1-2 นาที เพราะต้องดาวน์โหลดส่วนประกอบ ครั้งต่อไปเปิดได้ทันที เบราว์เซอร์จะเด้งขึ้นเองที่ `http://localhost:4140`

ปิดโปรแกรมด้วยการปิดหน้าต่างสีดำ

## ล็อกอิน

ใช้บัญชีแอดมินเดียวกับแอปหลัก ค่าตั้งต้นคือ

| ช่อง | ค่า |
| --- | --- |
| Username | `admin` |
| Password | `LiveBMKode@2026` |

ควรเปลี่ยนรหัสผ่านนี้ก่อนใช้งานจริง เพราะเป็นค่า default ที่อยู่ในโค้ด

## สิ่งที่ทำได้

- เพิ่ม แก้ไข ลบ ลูกค้า พร้อมตั้งรหัสผ่านและวันหมดอายุ
- เพิ่ม แก้ไข ลบ แพ็กเกจ กำหนดจำนวนช่องและอายุการใช้งาน
- เพิ่ม แก้ไข ลบ ประกาศที่จะแสดงในแอปของลูกค้า
- ดูสรุปจำนวนลูกค้าที่ยังไม่หมดอายุ

## สิ่งที่ทำไม่ได้

**จำนวนช่องที่ลูกค้าใช้จริงจะแสดงเป็น 0 เสมอ**

เพราะบัญชี TikTok ของลูกค้าเก็บอยู่ในไฟล์ `data/state.json` บนเครื่องลูกค้าแต่ละคน ไม่ได้อยู่บน MongoDB ถ้าต้องการดูตัวเลขจริงต้องเปิดแอปหลักในเครื่องนั้น

ส่วน `channelLimit` ที่มาจากแพ็กเกจแสดงถูกต้องปกติ

## ไฟล์ .env

ไฟล์นี้เก็บรหัสผ่าน MongoDB **ห้าม commit ขึ้น git และห้ามส่งให้ลูกค้า**

`START-ADMIN.bat` จะคัดลอกมาจากโฟลเดอร์ `rerun_tiktok_bmkode` ให้อัตโนมัติถ้าวางสองโฟลเดอร์นี้ไว้ที่เดียวกัน ถ้าย้ายที่ต้องคัดลอกเอง

ต้องเป็น connection string ตัวเดียวกับแอปหลัก ไม่งั้นจะเห็นข้อมูลคนละชุด

## พอร์ต

AdminWEB ใช้พอร์ต `4140` ส่วนแอปหลักใช้ `4130` จึงเปิดพร้อมกันได้ เปลี่ยนได้ที่ `ADMIN_PORT` ใน `.env`

## แก้ปัญหา

| อาการ | สาเหตุและวิธีแก้ |
| --- | --- |
| `ไม่พบ Node.js` | ติดตั้งจาก https://nodejs.org เลือกเวอร์ชัน LTS |
| `ไม่พบไฟล์ .env` | คัดลอก `.env` จากโฟลเดอร์ `rerun_tiktok_bmkode` มาวางในโฟลเดอร์นี้ |
| `bad auth : authentication failed` | รหัสผ่าน MongoDB ใน `.env` ผิด ไปรีเซ็ตที่ Atlas แล้วแก้ใหม่ |
| `IP that isn't whitelisted` | IP เครื่องเปลี่ยน ไปเพิ่มใหม่ที่ Atlas เมนู Network Access |
| เปิดแล้วขึ้น `EADDRINUSE` | พอร์ต 4140 ถูกใช้อยู่ ปิดหน้าต่างเก่าก่อน หรือเปลี่ยน `ADMIN_PORT` |
